========================================================================
 슈퍼로봇대전 OG 문 드웰러즈 한국어 패치 변경 내역
========================================================================

v20260818

- 부대편성 검색 팝업의 깨진 점선·괄호·ON/OFF 글리프를 복원했습니다.
- 정신기·특수스킬·특수능력·어빌리티 검색에서 나오던 퉁·튀·튕·튜·토
  오염 문자를 제거했습니다. (검색 포맷터 전용 글리프 영역 U+A000~U+A015를
  한국어 폰트가 재사용한 것이 원인 — 한글 21자를 안전한 영역으로 이주)
- 검색 제목을 `검색항목`, `검색 우선순위`로, 행 번호를 1~5로 정리했습니다.
- 편입 메뉴의 `[편입] 기체 선택`, `편입`, `초기화` 표기를 수정했습니다.
- 부대 정보 탭을 `정보 1`, `정보 2`로 구분했습니다.
- 갈아태우기 확인 질문과 `네/아니요`가 표시되지 않던 문제와 커서 위치를
  수정했습니다.
- 기체명을 `빌트랩터`, `빌트랩터（ＦＭ）`로 수정했습니다.
- 파츠 해제 화면의 `해제`, `잔여`, `해제 한다` 표기를 수정했습니다.
- `스크류 모듈` 명칭과 설명을 수정했습니다.
- 정신기 `연`, 자동편성 `앞채움` 등 기존 누적 보정을 유지했습니다.
- xdelta 4개를 일본판 원본에 역적용해 최종 PSARC SHA-256 4/4 일치를
  검증했습니다. 빠른 패처의 내장 대상 해시도 동일 기준으로 갱신했습니다.
- 하유하우님의 검색 화면 제보 덕분에 수정할 수 있었습니다.

v20260816b

- 기체·파일럿 특수능력 표의 `방패`를 압축 합성 글자가 아닌 정상 폭 두 글자로 복원했습니다.
- `원호공격`을 압축 합성 글자가 아닌 정상 폭 네 글자로 복원했습니다.
- 인터미션 옵션 설명을 `각종 설정을 합니다.`로 교정했습니다.
- 어빌리티 명칭 `사정+`를 `사거리+`로 교정했습니다.
- 라이오의 이름이 `뇌봉`으로 표시되는 문제를 수정했습니다.
- 시작 시 경고문, 첫 화면 로고와 시나리오 제목 한글화를 유지했습니다.

- 이미지 한글화 적용 범위를 시작 시 경고문과 첫 화면 로고 2개로 제한했습니다.
- 그 밖의 이미지 교체는 모두 배포 대상에서 제외했습니다.
- `근위대장` 텍스트는 변경하지 않았습니다.
- 빠른 ISO 구간 패처와 기존 xdelta 설치 방식을 하나의 배포본으로 통합했습니다.
- 두 설치 방식이 동일한 최신 Common/General2d/Logic/Battle 결과를 만들도록 갱신했습니다.
- 최신 이미지 한글화 및 2026-08-16 기준 데이터 수정 사항을 양쪽 방식에 모두 반영했습니다.
- xdelta 패치 4개를 일본판 원본에 역적용해 최종 PSARC SHA-256 4/4 일치를 검증했습니다.
- 빠른 ISO 패처에 백업 기반 빠른 검사, 원본 복구, RPCS3 경로 검사,
  기존 dev_hdd0\game\BLJS10335 설치 데이터 선택 삭제 기능을 포함했습니다.
- 일반 GUI 실행 시 콘솔 창이 나타나지 않도록 구성했습니다.
- 패처와 설치 스크립트는 PPU/SPU/셰이더 캐시 및 세이브 데이터를 삭제하지 않습니다.
- 전투 HUD 공유 이미지(cosl.dds) 현지화를 제외해 HP·EN·기체명 누락을 복구했습니다.
- General2d 공유 글리프 이미지(tex_06.dds) 현지화를 제외해 레벨업 글자 깨짐을 복구했습니다.
- 타이틀 로고의 푸른색 외곽선은 일본판 원본 디자인과 동일하게 유지했습니다.
- 시나리오 제목 한글화 88건을 유지하고, 일본어가 남지 않았는지 전수 검사했습니다.
- 시나리오 지역명 316건을 전수 검사해 전각 공백 잔존 0건을 확인했습니다.
- 아군/적 부대표 화면 제목과 세력 전환, 참가하지 않습니다 문구를 교정했습니다.
- 숫자·기호·미확인 적 정보 템플릿 505건을 원문과 대조해 누락된 숫자, %, ±, ? 표시를 복구했습니다.

- 옵션 화면의 '트', '특' 아이콘 자리

- '원호공격L2' 공백

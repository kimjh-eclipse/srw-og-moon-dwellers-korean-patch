## 설치

**[최신 설치 안내](https://kimjh-eclipse.github.io/srw-og-moon-dwellers-korean-patch/#/install)**에 다운로드·적용 경로·검증·복구 절차를 통합했습니다. 소스 ZIP이 아닌 Releases의 배포 ZIP을 전부 풀어 사용하세요.

RPCS3를 종료하고 백업한 뒤 아래 중 하나만 선택합니다.

- ISO: EXE의 `ISO 원본 검사` → `ISO에 한국어 패치 적용`.
- 폴더 GUI: `폴더 게임 상태 검사` → `RPCS3 / 폴더 게임에 직접 패치`.
- 폴더 PowerShell: `install_xdelta.ps1 -TargetDir "대상 PSARC 경로"`.

대상은 PSARC 5개와 제목·아이콘 2개입니다. 이전 버전은 이전 도구·백업으로 복구한 뒤 새 백업 경로로 적용하세요.

폴더 검증은 `verify_xdelta.ps1`, 폴더 복구는 `restore_xdelta_backup.ps1`을 사용합니다. ISO는 EXE의 `원본으로 복구`와 해당 ISO 백업을 사용합니다.

ISO용 자동 정리는 폴더 직접 패치에 적용되지 않으며, 하위 SPU 캐시는 수동 정리가 필요합니다. **hdd0를 직접 패치했다면 그 설치 데이터 폴더를 삭제하지 마세요.**

아카이브 재생 중지 확인창은 별도 RPCS3 선택 패치를 활성화해야 합니다. 자세한 경로와 절차는 위 설치 안내를 따르세요.

## 알려진 제한

완전 무결한 100% 한글화가 아닙니다. 자세한 내용은 [알려진 문제](docs/known-issues.md)를 읽어 주세요.

### 1. 화면이 하얗게 보일 때 — SPU 캐시를 지우세요

타이틀이나 메뉴 화면이 흰색으로 보일 수 있습니다. 커서 이동과 소리는 정상인데
그림만 안 나오는 상태입니다. RPCS3의 **SPU 캐시가 쌓이면서** 생기는 현상입니다.

> **1단계 — `libvdec.sprx` 를 LLE로 바꿉니다 (먼저 하셔야 합니다)**
> 게임 우클릭 → **Change Custom Configuration** → **Advanced** 탭 →
> **Firmware Libraries** 목록에서 **`libvdec.sprx`** 를 체크합니다.
> 기본값은 HLE이고, 체크하면 LLE가 됩니다.
>
> **2단계 — SPU 캐시를 지웁니다**
> RPCS3 게임 목록에서 해당 게임을 우클릭 → **Remove** → **Remove SPU Cache**
> 그 뒤 다시 실행하면 정상으로 돌아옵니다.

**1단계를 건너뛰면 캐시를 지워도 다시 하얗게 보입니다.** 순서대로 해 주세요.
이 설정은 초반에 뜨는 오류 표시도 함께 없애 줍니다.

**한 번 지웠다고 끝나지 않습니다.** 플레이를 계속하면 캐시가 다시 쌓이면서 재발합니다.
증상이 보이면 그때마다 같은 방법으로 지우면 됩니다.

**빠른 패처의 자동 정리는 ISO 적용에만 해당하며 하위 폴더 SPU 캐시는 처리하지 않습니다.**
반면 `install_xdelta.ps1`은 캐시를 변경하지 않습니다. 수동 정리가 필요하면 위 `Remove SPU Cache`를 사용하세요.
`cache\BLJS10335` 폴더 전체나 PPU 캐시, 셰이더 캐시는 지우지 마세요.

> v20260813까지의 `install.ps1` 은 설치할 때 SPU 캐시를 자동으로 지웠습니다.
> v20260814부터 해당 동작을 뺐습니다. 이 과거 스크립트의 동작과 현재 빠른 패처의 정리 옵션은 별개입니다.

**패치를 적용하지 않은 원본 상태에서도 동일하게 발생**하며, RPCS3 버전을 바꿔도 같습니다.
이 패치 때문에 생기는 문제가 아닙니다.

> 이전 버전 문서는 이 현상의 원인을 "로고 뒤 흰 화면에서의 조기 입력"으로 안내했습니다.
> **그 안내는 틀렸습니다.** 원인 추적 기록은 [실기 검증과 오판 정정](docs/verification.md)에 있습니다.

### 2. 지형 표시의 한자

일부 화면에서 지형이 `空` `陸` `海` `宇`로 표시됩니다.
공/지/해/우로 바꾸면 글자가 사라지거나 다른 화면이 깨지는 문제가 있어 한자 유지를 결정했습니다.

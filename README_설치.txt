========================================================================
 슈퍼로봇대전 OG 문 드웰러즈 한국어 패치 (PS3 일본판)
 버전 v20260813  ·  설치 안내
========================================================================

■ 적용 대상

  슈퍼로봇대전 OG 더 문 드웰러즈 일본판
  게임 ID : BLJS10335

  이 패치는 위 일본판에만 적용됩니다.
  원본 게임 데이터는 본인이 직접 준비해야 합니다.
  이 배포물에는 게임 파일이나 ISO가 들어 있지 않습니다.


========================================================================
 가장 중요한 것 — 어디에 패치할 것인가
========================================================================

  이 게임과 관련된 폴더는 두 곳입니다. 헷갈리기 쉬우니 먼저 정리합니다.

  (1) 롬  ← 여기에 패치합니다
      ...\BLJS10335\PS3_GAME\USRDIR\PSARC
      예: C:\RPCS3\games\BLJS10335\PS3_GAME\USRDIR\PSARC

  (2) 게임 데이터  ← 여기가 아닙니다
      <RPCS3 폴더>\dev_hdd0\game\BLJS10335\USRDIR\PSARC

  (2)번은 게임이 처음 실행될 때 (1)번에서 복사해 만드는 사본입니다.
  사본만 바꾸면 게임이 무결성 검사에서 걸려

      "게임 데이터가 손상되었습니다"

  라는 메시지가 뜨고 진행되지 않습니다.

  반드시 (1) 롬 쪽에 패치하고, (2) 게임 데이터 폴더는 삭제해서
  게임이 다시 만들도록 하세요.


========================================================================
 자동 설치 (권장)
========================================================================

  1. RPCS3를 완전히 종료합니다.

  2. 받은 파일의 압축을 풉니다.

  3. 압축을 푼 폴더에서 PowerShell을 엽니다.
     (폴더 빈 곳에서 Shift + 마우스 오른쪽 클릭
      -> "여기에 PowerShell 창 열기")

  4. 아래를 실행합니다. 경로는 본인 롬 위치로 바꾸세요.

     .\install.ps1 -TargetDir "C:\RPCS3\games\BLJS10335\PS3_GAME\USRDIR\PSARC"

     실행이 막히면 아래를 먼저 입력하고 다시 하세요.

     Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

  5. 스크립트가 끝나면 안내에 따라 아래 폴더를 삭제합니다.

     <RPCS3 폴더>\dev_hdd0\game\BLJS10335

     세이브 데이터는 여기가 아니라
     dev_hdd0\home\00000001\savedata 에 있으므로 안전합니다.

  6. 게임을 실행합니다. 데이터 설치가 진행된 뒤 한국어로 표시됩니다.


  스크립트가 하는 일

    RPCS3 실행 여부 확인
    대상 경로가 롬인지 게임 데이터인지 판별하고 알려줌
    원본 네 파일의 크기와 SHA-256 검증
    원본을 backup_original_<날짜시간> 폴더에 백업
    임시 파일에 패치 적용 -> 해시 검증 -> 통과한 것만 교체
    원래 수정시각 복원
    이 게임의 SPU 캐시 삭제

  검증에 실패하면 게임 파일을 건드리지 않고 중단합니다.
  실패했다고 원본을 삭제하거나 게임 폴더를 정리하는 동작은 하지 않습니다.


========================================================================
 수동 설치
========================================================================

  자동 설치를 쓸 수 없을 때 사용합니다.

  1. RPCS3를 완전히 종료합니다.

  2. 압축을 푼 폴더의 xdelta.exe 와 patches 폴더를
     롬의 PSARC 폴더 안에 복사해 넣습니다.

     예: C:\RPCS3\games\BLJS10335\PS3_GAME\USRDIR\PSARC

  3. 그 PSARC 폴더에서 PowerShell을 엽니다.
     (폴더 빈 곳에서 Shift + 마우스 오른쪽 클릭
      -> "여기에 PowerShell 창 열기")

  4. 아래 네 줄을 차례로 붙여넣어 실행합니다.
     경로는 본인 롬 위치로 바꾸세요.

     .\xdelta.exe -d -s "C:\RPCS3\games\BLJS10335\PS3_GAME\USRDIR\PSARC\Common.psarc.sdat" "patches\Common.psarc.sdat.xdelta" "Common.new"

     .\xdelta.exe -d -s "C:\RPCS3\games\BLJS10335\PS3_GAME\USRDIR\PSARC\Battle.psarc.sdat" "patches\Battle.psarc.sdat.xdelta" "Battle.new"

     .\xdelta.exe -d -s "C:\RPCS3\games\BLJS10335\PS3_GAME\USRDIR\PSARC\General2d.psarc.sdat" "patches\General2d.psarc.sdat.xdelta" "General2d.new"

     .\xdelta.exe -d -s "C:\RPCS3\games\BLJS10335\PS3_GAME\USRDIR\PSARC\Logic.psarc.sdat" "patches\Logic.psarc.sdat.xdelta" "Logic.new"

  5. 만들어진 .new 파일 네 개를 원래 이름으로 바꿔 덮어씁니다.

     Common.new    -> Common.psarc.sdat
     Battle.new    -> Battle.psarc.sdat
     General2d.new -> General2d.psarc.sdat
     Logic.new     -> Logic.psarc.sdat

     원본을 먼저 다른 곳에 백업해 두시길 권합니다.

  6. 아래 게임 데이터 폴더를 삭제합니다.

     <RPCS3 폴더>\dev_hdd0\game\BLJS10335

  7. RPCS3 게임 목록에서 해당 게임을 마우스 오른쪽 클릭
     -> Remove -> Remove SPU Cache

  8. 게임을 실행합니다.

  수동 설치는 해시 검증을 건너뛰므로, 끝난 뒤 반드시 verify.ps1 을 실행하세요.


========================================================================
 설치 확인
========================================================================

    .\verify.ps1 -TargetDir "C:\RPCS3\games\BLJS10335\PS3_GAME\USRDIR\PSARC"

  네 파일이 모두 "한국어 패치됨" 으로 나오면 정상입니다.

========================================================================
 원본으로 되돌리기
========================================================================

    .\restore_backup.ps1 -TargetDir "C:\RPCS3\games\BLJS10335\PS3_GAME\USRDIR\PSARC"

  install.ps1 이 만든 backup_original_* 폴더에서 자동으로 복구합니다.
  백업이 진짜 원본인지 해시로 확인한 뒤에만 복구하므로 안전합니다.

  되돌린 뒤에도 게임 데이터 폴더를 삭제하고 다시 실행해야
  원본 상태로 완전히 돌아갑니다.

  게임 폴더를 통째로 지우지 마세요. 백업 복구만으로 충분합니다.


========================================================================
 권장 설정 — 초반 오류 메시지 없애기
========================================================================

  RPCS3 게임 목록에서 해당 게임 우클릭
    -> Change Custom Configuration
    -> Advanced 탭
    -> Firmware Libraries 목록에서 libvdec.sprx 체크

  게임 초반에 나오는 오류 표시가 생략됩니다.


========================================================================
 화면이 하얗게 보일 때
========================================================================

  RPCS3 게임 목록에서 해당 게임을 마우스 오른쪽 클릭
    -> Remove -> Remove SPU Cache

  그 뒤 다시 실행하면 정상으로 돌아옵니다.
  플레이를 계속하면 캐시가 다시 쌓여 재발할 수 있으니, 그때마다 지우면 됩니다.

  install.ps1 로 설치하면 설치 시점의 캐시는 자동으로 지웁니다.

  자세한 내용은 README_알려진문제.txt 를 참고하세요.

# 한국어 패치 v20260919

PS3 일본판 BLJS10335용 누적 패치입니다. v20260912의 전투 대사 참조 복구·가이던스와 이전 한글화를 포함합니다.

## 이번 수정

- 이슈 #7: 44·45화 제보와 다른 시나리오의 반복 오류를 포함해 44개 대사를 교정했습니다. 알리·쿨랑주·퓨레임 표기, 조사, 적에게 쓰는 존대와 비문을 정리했습니다.
- 이슈 #9: 초반 대사 4곳, 퀵 커맨드 문구 49곳, 지형 제목 405개(87종)를 교정했습니다.
- General3d가 추가되어 ISO 빠른 패처와 xdelta 대상은 **PSARC 5개 + 제목·아이콘 2개, 총 7개**입니다.
- 아카이브 재생 중단 확인창은 **별도 RPCS3 런타임 패치**로 제공합니다. `RPCS3_optional/README.txt`를 확인하세요. ISO만 패치해도 이 확인창까지 바뀌는 것은 아닙니다.

## 설치·업데이트

1. RPCS3를 종료하고 기존 백업을 보관하세요.
2. 이전 버전은 원본으로 복구한 뒤 이번 패치를 적용하세요. 예전 빠른 패처의 백업은 해당 예전 패처로 복구하세요. 이번 버전은 대상 파일이 늘어 예전 백업을 그대로 재사용하지 못할 수 있습니다.
3. ISO 빠른 패처 또는 xdelta 중 하나를 사용하세요.
4. 기존 BLJS10335 설치 데이터가 남으면 옛 데이터가 먼저 읽힙니다. 빠른 패처의 설치 데이터·SPU 캐시 정리 옵션과 RPCS3 경로를 확인하세요. xdelta 설치는 사용법에 따라 직접 정리해야 합니다.

세이브 데이터는 삭제하지 않습니다. 원본 게임이나 ISO는 배포하지 않습니다.

## 검증 범위와 남은 확인

- xdelta 7개 적용 결과 SHA-256 대조.
- 실제 빠른 패처 EXE로 원본과 같은 내부 경로·대상 7개 원본 파일을 담은 축소 ISO9660 시험본에 적용하고, 각 파일 해시 및 복구 후 시험본 전체 해시 대조. Battle 다중 extent도 시험했습니다. 원본 ISO 전체 사본의 배치나 게임 실행 검증은 아닙니다.
- 폴더 설치·검증·복구 스크립트 실행과 7개 파일 해시 대조, 수정시각 보존 확인.
- ZIP 내부 파일의 SHA-256 검증.

**이번 교정의 실제 게임 화면 검증은 아직 완료되지 않았습니다.** 위 검증은 파일·패치 도구 검증이며, 게임 실행 검증과 다릅니다. 특히 44·45화 대사, 퀵 커맨드, 지형명, 선택형 아카이브 팝업을 확인해 주시면 감사하겠습니다.

## 빠른 설치

RPCS3를 종료하고 배포 ZIP을 전부 푼 뒤 한 가지 방식만 선택하세요.

- ISO: EXE의 `ISO 원본 검사` → `ISO에 한국어 패치 적용`.
- 폴더 GUI: `폴더 게임 상태 검사` → `RPCS3 / 폴더 게임에 직접 패치`.
- 폴더 PowerShell: `install_xdelta.ps1 -TargetDir "대상 PSARC 경로"`.

이전 버전은 이전 도구·백업으로 복구한 뒤 적용합니다. 대상은 PSARC 5개와 제목·아이콘 2개입니다.
ISO용 자동 정리는 폴더 직접 패치에 적용되지 않으며 하위 SPU 캐시도 수동 정리가 필요합니다.
hdd0를 직접 패치했다면 그 설치 데이터 폴더를 삭제하지 마세요.

다운로드·검증·복구·별도 팝업 패치 절차는 [최신 설치 안내](install.md)를 참고하세요.

## 이 프로젝트에서 얻은 것

**배포 델타 크기는 "내용이 얼마나 바뀌었나"가 아니라 "평문 오프셋이 밀리지 않았나"로 결정됩니다.**

SDAT은 블록번호로 키를 유도하는 블록 독립 암호화라, 같은 인덱스에 같은 평문이 오면
암호문도 같습니다. 그런데 PSARC를 표준 방식으로 재패킹하면 zlib 압축 결과 크기가 달라져
뒤쪽 오프셋이 전부 밀리고, **내용이 거의 안 바뀌어도 파일 전체가 다른 바이트가 됩니다.**

실제로 `Common`은 1,171개 엔트리 중 **단 1개**(`/Dat/Font/font.bin`)만 내용이 달랐는데도
표준 재패킹본의 델타는 505.4MB, 원본 크기의 99.9%였습니다.

엔트리 오프셋과 블록 테이블을 원본 그대로 보존하도록 재빌드하자 결과가 이렇게 바뀌었습니다.

| 파일 | 표준 재패킹 | 고정 배치 | 축소 |
|---|---:|---:|---:|
| `Common` | 505,369,094 | **1,766,676** | 286배 |
| `General2d` | 120,784,668 | **884,986** | 136배 |
| `Logic` | 38,373,163 | **1,932,742** | 20배 |
| `Battle` | 3,088,954 | 3,088,954 | — |
| **합계** | **667,615,879** | **7,673,358** | **87배** |

자세한 경위는 [고정 배치 재빌드](fixed-layout.md)에 정리했습니다.

이 문서와 저장소는 **원본 게임에서 추출한 텍스트·이미지·폰트·번역 대역 데이터를 포함하지 않습니다.**

패치 적용에는 본인이 합법적으로 소유한 원본 게임 데이터가 필요합니다.

이 프로젝트는 비공식 팬 번역이며 권리자와 아무 관련이 없습니다.

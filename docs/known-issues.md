# 알려진 문제

이 패치는 완전 무결한 100% 한글화가 아닙니다.
현재 남은 안내와 해결된 항목을 구분합니다. 2026-09-19 사용자 확인을 반영해,
이미 수정된 문제를 미해결로 적었던 과거 안내를 정정했습니다.

## 1. 화면이 하얗게 보일 때 — SPU 캐시를 지우세요

### 증상

타이틀이나 메뉴 화면이 흰색으로 보입니다.
커서 이동·선택·사운드는 정상인데 **그림만 나오지 않습니다.**

### 해결 방법

**순서가 중요합니다.** 1단계를 건너뛰고 캐시만 지우면 다시 하얗게 보입니다.

> **1단계 — `libvdec.sprx` 를 LLE로 바꿉니다**
>
> 게임 우클릭 → **Change Custom Configuration** → **Advanced** 탭 →
> **Firmware Libraries** 목록에서 **`libvdec.sprx`** 를 체크합니다.
>
> 기본값은 HLE입니다. 체크하면 LLE가 되고, 항목 위에 마우스를 올리면
> `Select to LLE. (HLE by default)` 라는 설명이 뜹니다.
>
> 설정을 저장하고 창을 닫습니다.

> **2단계 — SPU 캐시를 지웁니다**
>
> RPCS3 게임 목록에서 해당 게임을 마우스 오른쪽 클릭
> → **Remove** → **Remove SPU Cache**
>
> 그 뒤 다시 실행하면 정상으로 돌아옵니다.

1단계는 한 번만 하면 됩니다. 이 설정은 초반에 뜨는 오류 표시도 함께 없애 줍니다.

**2단계는 한 번 지웠다고 끝나지 않습니다.** 플레이를 계속하면 캐시가 다시 쌓이면서
재발합니다. 화면이 하얗게 보이기 시작하면 2단계를 다시 하시면 됩니다.

지워야 할 파일은 하나입니다.

```
<RPCS3 폴더>\cache\BLJS10335\ppu-<해시>-EBOOT.BIN\spu-safe-v1-tane.dat
```

PPU 캐시(`*.obj.gz`)와 셰이더 캐시는 이 문제와 무관합니다. 지우지 않아도 됩니다.

### 원인

RPCS3가 쌓아 둔 SPU 캐시가 게임 데이터와 어긋나면서 생깁니다.
게임 데이터를 교체한 뒤에는 특히 지우는 것이 안전합니다.

**한국어 패치를 적용하지 않은 원본 상태에서도 동일하게 발생하며**, RPCS3 버전을 바꿔도 같습니다.
이 패치 때문에 생기는 문제가 아닙니다.

> **이전 안내 정정**
> v20260808 문서는 이 현상을 "로고 뒤 흰 화면에서의 조기 입력"으로 설명하고
> "버튼을 누르지 말고 기다리라"고 안내했습니다. **그 안내는 틀렸습니다.**
> 원인 추적 기록은 [실기 검증과 오판 정정](verification.md)에 있습니다.

## 2. 지형 표시의 한자

일부 화면에서 지형이 원래 한자로 표시됩니다.

| 한자 | 뜻 |
|---|---|
| `空` | 공중 |
| `陸` | 지상 |
| `海` | 해상 |
| `宇` | 우주 |

공/지/해/우로 바꾸면 글자가 사라지거나 다른 화면이 깨지는 문제가 있어 한자 유지를 결정했습니다.

## 해결된 항목

2026-09-19 사용자 확인 기준으로 다음 항목은 수정 완료되었습니다.
최신 문서에 남아 있던 과거의 미해결 설명을 철회합니다.

- 정신기 대상의 `자신1기` 겹침
- 옵션 화면의 `트`, `특` 잔여 글자
- 세이브 목록의 루트·톱 에이스·시나리오 제목 표시
- 시나리오 데이터 불러오기 / 불러오기 화면 종료 확인 문구
- `컴패티 카이저` → `컴패터블 카이저` 표기
- 인터미션 `부대` 및 `원호공격L2` 표시 간격

“구조적으로 해결이 어렵다”, “제거를 포기했다”, “다음 버전에서 정리한다”는 종전 안내는
현재 상태를 반영하지 않습니다. 과거 변경 내역은 당시 기록으로만 읽어 주세요.
예전에 만들어진 세이브 목록의 표시가 남아 있다면 빠른 패처의 `세이브 목록 한글화 (PARAM.SFO)`
기능을 사용할 수 있습니다. 현재 세이브 표시가 항상 깨진다는 의미는 아닙니다.

위 시스템 확인창 2건과 **아카이브 재생 중단 확인창**은 별개입니다.
아카이브 확인창은 v20260919부터 별도 RPCS3 런타임 패치로 동봉되어 있으며,
그 변경의 실제 화면 검증은 아직 완료되지 않았습니다.

## 롬을 패치한 뒤에는 설치 데이터를 지우세요

**v20260909c부터** 패치는 파일 수정시각을 보존해 수정시각 변경으로 인한 설치 데이터 오류를 예방합니다.
모든 원인의 손상 오류가 발생하지 않는다는 보장은 아닙니다.

그런데 게임은 `<RPCS3 폴더>\dev_hdd0\game\BLJS10335` 설치 데이터가 남아 있으면
그 사본을 먼저 읽습니다. 지금까지는 위 오류가 "사본을 지워야 한다"는 신호 역할을 했는데,
그 신호가 사라졌으므로 **사본을 지우지 않으면 아무 경고 없이 패치가 적용되지 않은 화면**을
보게 됩니다.

이 안내는 ISO 또는 폴더형 원본을 패치한 경우입니다. **hdd0 설치 데이터를 직접 패치했다면 그 폴더를 삭제하지 마세요.**
빠른 패처의 정리 옵션은 ISO 적용에만 해당하며 하위 폴더 SPU 캐시는 처리하지 않습니다.
세이브는 `dev_hdd0\home` 아래에 있으며 정리 대상이 아닙니다. 상세 절차는 [최신 설치 안내](install.md)를 따르세요.

- 일부 UI 아이콘 글자
- 좁은 칸에 맞추기 위해 축약한 표기 — 예를 들어 `특수 스킬`은 좁은 칸에서 `특수기`로 표시됩니다

## 문제가 생겼을 때

1. 먼저 설치 상태를 확인합니다.
   ```powershell
   .\verify_xdelta.ps1 -TargetDir "<...\BLJS10335\USRDIR\PSARC>"
   ```
2. 원본으로 되돌리려면 복구 스크립트를 씁니다.
   ```powershell
   .\restore_xdelta_backup.ps1 -TargetDir "<...\BLJS10335\USRDIR\PSARC>"
   ```
3. **게임 폴더를 통째로 지우지 마세요.** 백업 복구만으로 충분합니다.

# 알려진 문제

이 패치는 완전 무결한 100% 한글화가 아닙니다.
아래는 확인된 상태이며, 검토 끝에 현재 형태를 유지하기로 한 것입니다.

## 1. 화면이 하얗게 보일 때 — SPU 캐시를 지우세요

### 증상

타이틀이나 메뉴 화면이 흰색으로 보입니다.
커서 이동·선택·사운드는 정상인데 **그림만 나오지 않습니다.**

### 해결 방법

> RPCS3 게임 목록에서 해당 게임을 마우스 오른쪽 클릭
> → **Remove** → **Remove SPU Cache**
>
> 그 뒤 다시 실행하면 정상으로 돌아옵니다.

**한 번 지웠다고 끝나지 않습니다.** 플레이를 계속하면 캐시가 다시 쌓이면서 재발합니다.
화면이 하얗게 보이기 시작하면 가장 먼저 이것부터 확인하세요.

지워야 할 파일은 하나입니다.

```
<RPCS3 폴더>\cache\BLJS10335\ppu-<해시>-EBOOT.BIN\spu-safe-v1-tane.dat
```

PPU 캐시(`*.obj.gz`)와 셰이더 캐시는 이 문제와 무관합니다. 지우지 않아도 됩니다.

### 원인

RPCS3가 쌓아 둔 SPU 캐시가 게임 데이터와 어긋나면서 생깁니다.
게임 데이터를 교체한 뒤에는 특히 지우는 것이 안전합니다.

**한국어 패치를 적용하지 않은 원본 상태에서도 동일하게 발생하며**, RPCS3 버전을 바꿔도 같습니다.
이 패치 때문에 생기는 문제가 아닙니다.

> **이전 안내 정정**
> v20260808 문서는 이 현상을 "로고 뒤 흰 화면에서의 조기 입력"으로 설명하고
> "버튼을 누르지 말고 기다리라"고 안내했습니다. **그 안내는 틀렸습니다.**
> 원인 추적 기록은 [실기 검증과 오판 정정](verification.md)에 있습니다.

## 2. 옵션 화면의 `트`, `특` 글자

옵션 화면 오른쪽에 `트`, `특`이 단독으로 남습니다.

해당 아이콘을 비우면 첫 메인 메뉴가 흰색으로 표시되는 문제가 재현되어,
부팅 안정성을 위해 제거를 포기했습니다. **게임 진행에는 영향이 없습니다.**

## 3. 지형 표시의 한자

일부 화면에서 지형이 원래 한자로 표시됩니다.

| 한자 | 뜻 |
|---|---|
| `空` | 공중 |
| `陸` | 지상 |
| `海` | 해상 |
| `宇` | 우주 |

공/지/해/우로 바꾸면 글자가 사라지거나 다른 화면이 깨지는 문제가 있어 한자 유지를 결정했습니다.

## 4. 정신기 대상의 `자신1기` 겹침

정신기 선택 화면에서 대상 표시가 `자신1기` 처럼 붙거나 겹쳐 보입니다.
데이터를 여러 방식으로 고쳐 봤으나 화면에서 해결되지 않았습니다.
위젯이 공백을 시각적으로 축소하거나 무시하는 것으로 보입니다.

## 5. 세이브 목록에 남는 원문

세이브 목록에서 항목 이름(`●루트`, `●자금` 등)은 한글이지만
루트 이름·톱 에이스 파일럿 이름·시나리오 제목은 깨져 보입니다.

이 게임은 화면 종류에 따라 다른 글꼴로 글자를 그립니다. 위 이름들은 게임 안에서도
표시되는 텍스트라 게임 글꼴에 맞춰야 하는데, 세이브 목록은 시스템 글꼴로 그려집니다.
같은 문자열이 두 조건을 동시에 만족할 수 없어 구조적으로 해결이 어렵습니다.

세이브 목록의 글자는 저장하는 시점에 기록되므로, 예전에 만든 세이브는 예전 문구를 유지합니다.

## 6. 시스템 확인창 2건

시나리오 데이터 불러오기 / 불러오기 화면 종료 확인창은 원래 자리보다 한글이 1바이트 길어
변환하지 않았습니다. 한자처럼 보일 수 있습니다.

나머지 시스템 확인창 49건은 v20260813에서 한글로 바꿨습니다.

## 7. `컴패티 카이저` 표기

정식 표기는 `컴패터블 카이저` 입니다. 기체 사전과 대사 일부, 전투 대사 한 곳까지
모두 14곳에 줄임 표기가 남아 있습니다.

대체 코드 인코딩에서는 글자마다 자리가 정해져 있어 세 바이트를 더 확보해야 합니다.
다음 버전에서 정리합니다.

## 8. 표시 공간이 좁은 항목

인터미션 메인 메뉴의 `부대`, 그리고 `원호공격L2` 의 공백이 좁게 나옵니다.

## 번역 범위 정리

### 한글화된 부분

- 주요 스토리 및 전투 대사
- 메뉴 및 인터페이스
- 파일럿 및 기체 정보
- 에이스 보너스, 특수기, 정신 커맨드

### 원문이 남는 부분

- 위 1~8번 항목
- 일부 UI 아이콘 글자
- 좁은 칸에 맞추기 위해 축약한 표기 — 예를 들어 `특수 스킬`은 좁은 칸에서 `특수기`로 표시됩니다

## 문제가 생겼을 때

1. 먼저 설치 상태를 확인합니다.
   ```powershell
   .\verify_xdelta.ps1 -TargetDir "<...\BLJS10335\USRDIR\PSARC>"
   ```
2. 원본으로 되돌리려면 복구 스크립트를 씁니다.
   ```powershell
   .\restore_xdelta_backup.ps1 -TargetDir "<...\BLJS10335\USRDIR\PSARC>"
   ```
3. **게임 폴더를 통째로 지우지 마세요.** 백업 복구만으로 충분합니다.

## 세이브 데이터

이 패치는 세이브 데이터 삭제를 요구하지 않습니다. 기존 세이브를 그대로 사용할 수 있습니다.
다만 만일을 대비해 설치 전 백업을 권장합니다.

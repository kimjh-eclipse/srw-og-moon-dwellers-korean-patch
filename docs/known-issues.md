# 알려진 문제

이 패치는 완전 무결한 100% 한글화가 아닙니다.
아래는 확인된 상태이며, 검토 끝에 현재 형태를 유지하기로 한 것입니다.

## 1. 타이틀 화면 백화 — 패치와 무관, 회피 방법 있음

### 증상

1. 로고 애니메이션이 끝난 직후 잠시 흰 화면이 나타납니다
2. **여기서 버튼을 먼저 누르면** 화면이 검게 바뀝니다
3. 타이틀 화면(`PRESS ANY BUTTON`)이 표시되지 않습니다
4. 이후 메뉴는 커서 이동·선택·사운드가 정상이지만 **화면만 흰색**으로 보입니다

> **회피 방법**
>
> 로고 뒤 흰 화면에서 **아무 버튼도 누르지 말고 기다리세요.**
> `PRESS ANY BUTTON`이 실제로 화면에 표시된 뒤에 입력하면 정상 동작합니다.

### 원인

타이틀 리소스 초기화가 끝나기 전에 입력이 들어가면 화면 전환 시퀀스가 어긋납니다.

**한국어 패치를 적용하지 않은 원본 상태에서도 동일하게 재현되며**, RPCS3 버전을 바꿔도 같습니다.
이 패치 때문에 생기는 문제가 아닙니다.

원인을 어떻게 좁혔는지는 [실기 검증과 오판 정정](verification.md)에 기록했습니다.

## 2. 옵션 화면의 `트`, `특` 글자

옵션 화면 오른쪽에 `트`, `특`이 단독으로 남습니다.

해당 아이콘을 비우면 첫 메인 메뉴가 흰색으로 표시되는 문제가 재현되어,
부팅 안정성을 위해 제거를 포기했습니다. **게임 진행에는 영향이 없습니다.**

## 3. 지형 표시의 한자

일부 화면에서 지형이 원래 한자로 표시됩니다.

| 한자 | 뜻 |
|---|---|
| `空` | 공중 |
| `陸` | 지상 |
| `海` | 해상 |
| `宇` | 우주 |

공/지/해/우로 바꾸면 글자가 사라지거나 다른 화면이 깨지는 문제가 있어 한자 유지를 결정했습니다.

## 번역 범위 정리

### 한글화된 부분

- 주요 스토리 및 전투 대사
- 메뉴 및 인터페이스
- 파일럿 및 기체 정보
- 에이스 보너스, 특수기, 정신 커맨드

### 원문이 남는 부분

- 위 1~3번 항목
- 일부 UI 아이콘 글자
- 좁은 칸에 맞추기 위해 축약한 표기 — 예를 들어 `특수 스킬`은 좁은 칸에서 `특수기`로 표시됩니다

## 문제가 생겼을 때

1. 먼저 설치 상태를 확인합니다.
   ```powershell
   .\verify.ps1 -TargetDir "<...\BLJS10335\USRDIR\PSARC>"
   ```
2. 원본으로 되돌리려면 복구 스크립트를 씁니다.
   ```powershell
   .\restore_backup.ps1 -TargetDir "<...\BLJS10335\USRDIR\PSARC>"
   ```
3. **게임 폴더를 통째로 지우지 마세요.** 백업 복구만으로 충분합니다.

다만 만일을 대비해 설치 전 백업을 권장합니다.

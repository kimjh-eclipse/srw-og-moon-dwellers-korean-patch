# 알려진 문제

이 패치는 완전 무결한 100% 한글화가 아닙니다.
아래는 확인된 상태이며, 검토 끝에 현재 형태를 유지하기로 한 것입니다.

## 1. 화면이 하얗게 보일 때 — SPU 캐시를 지우세요

### 증상

타이틀이나 메뉴 화면이 흰색으로 보입니다.
커서 이동·선택·사운드는 정상인데 **그림만 나오지 않습니다.**

### 해결 방법

> RPCS3 게임 목록에서 해당 게임을 마우스 오른쪽 클릭
> → **Remove** → **Remove SPU Cache**
>
> 그 뒤 다시 실행하면 정상으로 돌아옵니다.

**한 번 지웠다고 끝나지 않습니다.** 플레이를 계속하면 캐시가 다시 쌓이면서 재발합니다.
화면이 하얗게 보이기 시작하면 가장 먼저 이것부터 확인하세요.

지워야 할 파일은 하나입니다.

```
<RPCS3 폴더>\cache\BLJS10335\ppu-<해시>-EBOOT.BIN\spu-safe-v1-tane.dat
```

PPU 캐시(`*.obj.gz`)와 셰이더 캐시는 이 문제와 무관합니다. 지우지 않아도 됩니다.

### 원인

RPCS3가 쌓아 둔 SPU 캐시가 게임 데이터와 어긋나면서 생깁니다.
게임 데이터를 교체한 뒤에는 특히 지우는 것이 안전합니다.

**한국어 패치를 적용하지 않은 원본 상태에서도 동일하게 발생하며**, RPCS3 버전을 바꿔도 같습니다.
이 패치 때문에 생기는 문제가 아닙니다.

> **이전 안내 정정**
> v20260808 문서는 이 현상을 "로고 뒤 흰 화면에서의 조기 입력"으로 설명하고
> "버튼을 누르지 말고 기다리라"고 안내했습니다. **그 안내는 틀렸습니다.**
> 원인 추적 기록은 [실기 검증과 오판 정정](verification.md)에 있습니다.

## 2. 옵션 화면의 `트`, `특` 글자

옵션 화면 오른쪽에 `트`, `특`이 단독으로 남습니다.

해당 아이콘을 비우면 첫 메인 메뉴가 흰색으로 표시되는 문제가 재현되어,
부팅 안정성을 위해 제거를 포기했습니다. **게임 진행에는 영향이 없습니다.**

## 3. 지형 표시의 한자

일부 화면에서 지형이 원래 한자로 표시됩니다.

| 한자 | 뜻 |
|---|---|
| `空` | 공중 |
| `陸` | 지상 |
| `海` | 해상 |
| `宇` | 우주 |

공/지/해/우로 바꾸면 글자가 사라지거나 다른 화면이 깨지는 문제가 있어 한자 유지를 결정했습니다.

## 번역 범위 정리

### 한글화된 부분

- 주요 스토리 및 전투 대사
- 메뉴 및 인터페이스
- 파일럿 및 기체 정보
- 에이스 보너스, 특수기, 정신 커맨드

### 원문이 남는 부분

- 위 1~3번 항목
- 일부 UI 아이콘 글자
- 좁은 칸에 맞추기 위해 축약한 표기 — 예를 들어 `특수 스킬`은 좁은 칸에서 `특수기`로 표시됩니다

## 문제가 생겼을 때

1. 먼저 설치 상태를 확인합니다.
   ```powershell
   .\verify.ps1 -TargetDir "<...\BLJS10335\USRDIR\PSARC>"
   ```
2. 원본으로 되돌리려면 복구 스크립트를 씁니다.
   ```powershell
   .\restore_backup.ps1 -TargetDir "<...\BLJS10335\USRDIR\PSARC>"
   ```
3. **게임 폴더를 통째로 지우지 마세요.** 백업 복구만으로 충분합니다.
